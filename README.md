## ✨ Project Overview

**English Vocabulary Explorer** is a feature-rich mobile application designed to help beginners and intermediate learners systematically master core English vocabulary and conversational basics. The app utilizes a structured category approach, supported by interactive modules, quizzes, and comprehensive progress tracking.

This entire application is built using the **Flutter** framework, ensuring a beautiful, consistent, and performant experience across both iOS and Android platforms.

### 🎯 Core Learning Categories

The learning content is organized into essential, foundational topics:

* **🔢 Numbers:** Counting and numerical expressions.
* **👨‍👩‍👧‍👦 Family Members:** Vocabulary for relatives and relationship terms.
* **🎨 Colors:** Names and associated descriptive vocabulary.
* **🦁 Animals:** Common animal names and related adjectives.
* **🗣️ Dialogue:** Basic conversational phrases and sentence structures.

## 💻 Key App Screens & Architecture

The application is structured to provide a comprehensive learning journey, from initial sign-up to daily mastery tracking.

| Screen / Feature | Description | Importance |
| :--- | :--- | :--- |
| **Welcome & Onboarding Flow** | Initial sequence guiding new users through the app's benefits and features. | Improves user retention and feature discovery. |
| **Category Selection** | Main screen allowing users to choose the vocabulary category they want to study (Numbers, Family, etc.). | Core navigational hub. |
| **Learning Modules** | Interactive flashcards, audio pronunciation, and visual aids for each specific category. | Primary content delivery system. |
| **Progress Tracking Dashboard** | Visual metrics showing user mastery level, completed quizzes, and study streaks. | Motivates continued use and measures success. |
| **Quiz Challenge** | Dedicated testing area with randomized questions across all categories to assess retention. | Critical for knowledge reinforcement. |
| **User Profile** | Personal settings, historical achievements, and user-specific data. | Personalization and achievement recognition. |
| **Daily Reminder Settings** | Allows users to customize the time and frequency of study notifications. | Drives daily engagement and consistency. |
| **App Settings** | Controls for general app functionality (e.g., sound toggles, language preferences). | User experience control. |
| **User Feedback / About Us** | Screens for contacting support, submitting feedback, and viewing app version/credits. | Community engagement and transparency. |

## 🚀 Getting Started

These instructions will help you set up and run the project locally.

### Prerequisites

* Flutter SDK installed and configured.
* A code editor (VS Code or Android Studio).

### Installation

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/MeshMalek/english-explorer.git](https://github.com/MeshMalek/english-explorer.git)
    cd english-explorer
    ```

2.  **Install dependencies:**
    ```bash
    flutter pub get
    ```

3.  **Run the application:**
    Connect a device or start an emulator, then execute:
    ```bash
    flutter run
    ```
